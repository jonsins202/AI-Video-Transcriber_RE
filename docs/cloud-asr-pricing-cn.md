# 国内云端 ASR API 调研（录音文件识别 / 长音频转写）

> 调研日期：2026-10-10。所有价格均来自官方定价页 / 官方文档一手来源（附 URL），价格为时效性信息，采购前请以官网当日价格为准。
> 背景：本项目当前用本地 FunASR Paraformer-large（GPU 自建），音频以中文为主、兼顾英文/多语言，单文件常 1~4 小时。核心决策维度：价格、识别准确率；次要：长音频上限、多语言、说话人分离、标点。

> **后续调研**：阿里百炼 ASR 模型代际与选型（paraformer-v2 是否过时、fun-asr / qwen3-asr / qwen-audio-3.1 对比与准确率 benchmark）见 [cloud-asr-dashscope-models.md](cloud-asr-dashscope-models.md)（2026-10-10）。

## 1. 阿里云

阿里云有两条产品线，注意区分：

- **百炼（DashScope / Model Studio）大模型 API**：qwen3-asr-flash-filetrans、fun-asr、paraformer 系列，按音频秒数计费，**这是与本项目场景最匹配的产品**。
- **智能语音交互（NLS，老产品线，"通义听悟"的底层能力）**：录音文件识别 / 极速版 / 闲时版，按小时计费。

来源：[模型调用价格 - 阿里云百炼](https://help.aliyun.com/zh/model-studio/model-pricing)、[非实时语音识别用户指南](https://help.aliyun.com/zh/model-studio/non-realtime-speech-recognition-user-guide)（查询日期 2026-10-10）

| **qwen3-asr-flash-filetrans**（长音频异步转写） | 0.00022 元/秒 | **0.792** | 10 小时（开通/发布后 90 天内有效） |

关键能力（非实时语音识别用户指南）：

- **长音频上限：单文件 ≤ 2GB、≤ 12 小时**（Qwen3-ASR-Flash-Filetrans / Fun-ASR / Paraformer 异步转写）——完全覆盖本项目 1~4 小时场景，无需切片。
- **说话人分离**：支持（`diarization_enabled`），但**启用时建议音频 ≤ 2 小时**，否则可能失败或超时；仅支持单声道。
- **多语言**：qwen3-asr 系列为多语种大模型（自动判断语种，官方宣传支持中/英/日/韩/粤等 11+ 语种）；fun-asr-mtl 多语种版；paraformer 以中英为主。
- **标点/时间戳**：全部返回标点；句级时间戳默认开启，qwen3-asr-filetrans 支持字级时间戳（限中/英/日/韩/德/法/西/意/葡/俄）。
- **准确率声明**：官方称 qwen3-asr-flash "基于千万小时音频数据、高精度、高鲁棒"，未给出公开 WER/CER 数字。
- **调用方式**：异步任务（提交 URL → 轮询/回调），查询接口默认 20 QPS（可扩至 100）；需公网可访问的音频 URL（本地直传限 100 QPS）。
- **敏感词过滤默认开启**（`system_reserved_filter` 默认 true，会替换为 `*`）——做逐字稿场景需注意显式关闭。

## 7. 对本项目的结论与坑

**价格维度**（中文长音频转写）：

1. **阿里百炼 paraformer-v2（0.288 元/小时）是绝对地板价**，约为其他家的 1/3~1/10，且每月 10 小时免费额度（每月循环发放，非一次性）。模型就是本项目本地跑的 Paraformer 同源（v2 更新），迁移心智成本最低。
2. 第二梯队：**火山豆包录音文件识别 2.0 / 腾讯录音文件识别大模型 2.0，均 0.8 元/小时**（后付费无梯度，小用量友好）；火山资源包 30 万小时可到 0.67，但预付量太大不现实。
3. 讯飞（4.9~9.9 元/小时）在本场景下价格无竞争力；百度后付费 2 元/小时且只支持中英。

**准确率维度**：

- 没有一家公布可横向对比的公开 WER/CER。百度/讯飞的 "98%" 是限定场景（近场中文）的宣传值；火山的 "错误率降 30~50%" 是相对自家传统模型的相对值。**实际准确率必须用本项目真实音频（B站/播客/多人对话）各跑几个样本实测**，建议用各家免费额度做 A/B。
- 大模型代际（qwen3-asr、豆包 Seed-ASR 2.0、腾讯大模型 2.0）在噪声、方言、专名、上下文纠错上普遍强于传统引擎；paraformer-v2 属上一代专用模型，胜在价格。

**坑/注意事项**：

- 阿里 paraformer 与 qwen3-asr **开说话人分离时建议 ≤2 小时**，本项目 1~4 小时音频若需要说话人分离是风险点；腾讯（≤5h、自动分 20 人）和火山（≤10 人）限制更宽松。
- 阿里百炼异步转写**默认开启系统敏感词过滤**（结果替换为 `*`），需显式 `system_reserved_filter=false`。
- 讯飞返回结果默认做"顺滑"（删语气词），做逐字稿要关 `eng_smoothproc`。
- 百度是异步排队"12 小时内返回"，时效明显差于别家。
- 火山/阿里 filetrans 均要求**公网可访问的音频 URL**，本地上传场景需要先做对象存储/临时 URL 这一层。
- 免费额度规则差异大：阿里 paraformer 每月 10h 循环、腾讯通用版每月 10h、讯飞一次性 50h/年、阿里 qwen3-asr 只有 90 天有效。
- 成本参考：按 0.288 元/小时算，4 小时音频转写约 1.15 元；0.8 元/小时则约 3.2 元——相比本项目 LLM 优化阶段的 token 成本，ASR 上云的成本都不算大头，准确率和工程适配才是主要决策依据。
